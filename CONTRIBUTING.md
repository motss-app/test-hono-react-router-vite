# Contributing Guide

## Project Setup

This project uses **Deno**. Please ensure you have Deno installed.

## Development

- **Install dependencies**: `deno install`
- **Start development server**: `deno task dev`
- **Build for production**: `deno task build`
- **Linting**: `deno task lint`
- **Formatting**: `deno task format`

**Note:** Do not use `npm` commands. Use `deno` for all package management and script execution.
